**How to use**

open .circ file in logisim evolution.

in the design tree go to main

with right mouse button click on BRAM and click view BRAM.

on the RAM with click with right mouse button and select LOAD image.

in the file explorer find and choose .txt file with code.

select highest auto-tick frequency and start simulation.

**with test code provided**

in the decimal number PIN you can type any number.

by selecting keyboard element and typing 1 the code will output the nth fibonacci where n is the number typed in the PIN.

by typing 2 in the keybord the code will create an RGB image.

by typing 3 it will output hello world!

by typinh 4 it will echo any inputs to the screen (z is stop)
